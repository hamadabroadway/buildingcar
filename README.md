# Building Car — Location de Voitures de Prestige

Site vitrine pour **Building Car**, agence de location de voitures au Maroc (Essaouira & Casablanca).

## Fonctionnalités

- Catalogue de 13 véhicules avec prix et spécifications
- Formulaire de réservation avec estimation de prix en temps réel
- Envoi de la demande directement via WhatsApp
- Design responsive (mobile, tablette, desktop)
- Bouton WhatsApp flottant

## Stack

HTML · CSS · JavaScript vanilla — aucune dépendance.

## Déploiement

Le site est déployé via **GitHub Pages** depuis la branche `main`.

## Développement local

Ouvrir `index.html` dans un navigateur ou lancer un serveur local :

```bash
npx serve .
```
